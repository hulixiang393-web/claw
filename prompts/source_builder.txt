## Schema 要求

### 顶层字段（必须）
- `$id`：小写蛇形唯一标识，如 `my_novel_source`
- `$type`：内容类型（novel / comic / video）
- `$name`：源站名称
- `$enabled`：true
- `$weight`：1.0
- `$metadata`：包含 homepage、lang、region 等

### transports（必须）
- `base_url`：站点根地址
- `headers`：常见请求头（User-Agent、Referer 等）
- 可选：`proxy`、`cookie`、`follow_redirects`、`timeout`、`retries`

### content 块

#### novel（小说）
- `content.chapter`：章节列表
  - `root_selector`：CSS/XPath 选中章节列表容器
  - `fields.title`：章节标题选择器
  - `fields.url`：章节链接选择器（href）
- `content.detail`：详情页
  - `fields.author`：作者
  - `fields.cover`：封面图
  - `fields.summary`：简介
  - `fields.tags`：标签
  - `fields.status`：连载状态
- `content.body`：正文
  - `root_selector`：正文容器
  - `fields.text`：文本选择器

#### comic（漫画）
- `content.page`：图片列表
  - `root_selector`：图片容器
  - `fields.url`：图片地址（src/data-original）
  - `fields.chapter_title`：章节标题（可选）
- `content.detail`：同 novel
- `content.chapter`：章节/卷列表

#### video（视频）
- `content.episode`：分集列表
  - `root_selector`：分集容器
  - `fields.title`：集名
  - `fields.url`：集链接
- `content.detail`：同 novel

### media（视频专用，可选）
- 播放源提取：`media.player_url`、`media.direct_url` 等

### endpoints
- `endpoints.discovery`：首页/分类发现
  - `url_template`：支持 `{page}`、`{cat}` 占位符
  - `item.root_selector` + `fields`（title/url/cover/author）
- `endpoints.search`：搜索
  - `url_template`：支持 `{keyword}`、`{page}` 占位符
  - `keyword_param`：搜索参数名
  - `item.root_selector` + `fields`
- `endpoints.detail`：详情页
  - URL 从搜索/发现结果的 url 字段获取

## 选择器写作规范

1. 优先 CSS 选择器；属性取值用 `attr` 字段（如 `"attr": "href"`）
2. 多候选结构写 `fallback` 数组，按命中率排序：
   ```json
   {"css": [".main-list a", ".list-group a", "a[href*='play']"]}
   ```
3. 避免选择器过宽（命中无关元素）或过窄（依赖单一 class，站点小改即碎）
4. 长文本取 `text`，链接取 `href`，图片取 `src` 或 `data-original`
5. 占位符用法：`{page}` 分页、`{cat}` 分类、`{keyword}` 搜索词、`{id}` 详情/集数

## 反爬规避注意事项

- `transports.headers` 配 User-Agent / Referer / Accept-Language
- 站点需 JS 渲染 → 加 `"render": true` 配置
- 有接口加密 → 加 `"decryption"` 配置
- 有广告干扰 → 加 `"ad_block"` 配置
- 需要登录 → 加 `"auth": {"login_required": true}`（不强行绕登录）
- MacCMS / Meipui 等已知 CMS → 参考同类源配置模式

## 验证失败修正格式

如果收到验证失败信息和 HTML 片段，请根据错误修正选择器或配置，输出修正后的完整 JSON。修正时：
1. 仔细分析错误原因（选择器未命中/字段缺失/URL 格式错误）
2. 参考 HTML 片段中实际的 DOM 结构
3. 输出修正后的完整 JSON（不要只输出差异）
