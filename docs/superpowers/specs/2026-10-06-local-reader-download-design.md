# 本地下载与阅读器修复设计

日期：2026-10-06
状态：用户已批准设计，待规格文件复核
基线：`385de40 perf(ui): reduce discovery preload and fanqie wait`

## 目标

在保持启动性能优化基线不变的前提下，修复以下行为：

1. 小说和漫画下载任务并发抓取时，最终 EPUB 必须按目录章节顺序合并。
2. 线上小说正文可以显示正文图片，图片加载失败时仍保留文字阅读。
3. 本地 EPUB 小说支持图文混排，图片按正文顺序显示。
4. 本地 EPUB 漫画继续显示图片画廊。
5. 本地小说和漫画点击目录后，正确跳转并高亮对应章节。

## 范围约束

- 工作区以 `385de40` 为唯一基线；已回退提交之后的书源接入、懒加载页面错误处理和后续图片提交不恢复。
- 不改网络反爬、验证码、WAF 或登录逻辑。
- 不改变 `Content.fetch_chapter()` 的纯文本返回契约。
- 不改变下载历史 JSON 中大型运行时数据的持久化规则。
- 章节顺序以 `Detail.chapters` 的索引为准；选中的章节保持相对顺序，未选章节不进入 EPUB。

## 现状与根因

### 下载顺序

`DownloadQueue` 使用线程池并发下载章节，`Downloader._download_novel()`、`_download_comic()` 和批量漫画路径完成抓取后直接向 `task.epub_chapters` 追加材料。完成时间与章节索引无关，因此网络速度不同会导致 EPUB 顺序错乱。

### 线上小说图片

`Content._fetch_chapter_page()` 当前只返回正文文本和分页链接，正文选择器内的图片信息没有进入阅读器；`NovelView` 只设置文本 QLabel，因此图片无法显示。

### 本地目录跳转

`EpubView._populate_toc()` 创建目录项时没有写入 `Qt.UserRole` 章节索引，而 `_on_toc_clicked()` 从该角色数据读取索引，点击后得到空索引，无法调用正确章节。

### 本地图文混排

合并 EPUB 的 `split_single_document()` 当前发现图片时只返回图片列表并丢弃同一片段的文字；普通 XHTML 章节也按是否包含 `<img>` 二选一，无法保留同一章节内文字和图片的原始顺序。

## 设计

### 1. 有序章节材料

`DownloadTask.epub_chapters` 改为支持按章节索引定位的运行时材料。下载器在成功抓取后写入 `(index, title, payload)` 或等价的索引槽位，而不是按完成时机追加。最终合成前由统一方法生成：

- 过滤未选章节和空槽位；
- 按原始索引升序排列；
- 转换为现有 EPUB builder 所需的 `(title, text)` 或 `(title, image_bytes)` 结构；
- 对旧测试替身或已存在的无索引材料保持兼容，避免无意义破坏测试边界。

同一章节重试成功时覆盖原索引槽位，不能产生重复章节。并发下载、漫画批量下载、暂停恢复和失败重试都复用同一写入规则。

### 2. 线上小说正文图片

增加不破坏旧契约的新读取路径，返回 `(text, image_urls)`。图片只从正文选择器命中的节点提取，支持 `src`、`data-src`、`data-original` 和 `data-lazy-src`，解析相对地址并去重；图片解析失败不影响文字返回。

`NovelView` 在滚动模式使用新的结果：

- 文字仍由正文 QLabel 显示；
- 图片通过现有异步图片加载边界加载并按阅读区宽度等比缩放；
- 图片下载失败或返回空图时跳过图片，文字保持可读；
- 章节代次和图片加载代次同时校验，换书、换章或关闭图片后，旧回调不得插入当前正文；
- 翻页模式继续以纯文字为主，避免动态图片高度破坏分页结果；
- 设置页增加 `reader.show_images`，默认开启，并支持运行时切换。

图片请求传递当前章节 URL 作为 Referer，不写入正文缓存字符串。

### 3. 本地 EPUB 图文显示

扩展本地章节模型，使一个章节可以保存有序内容片段，例如文字片段和图片引用片段。解析 XHTML 时按 DOM 文档顺序收集段落、换行和图片，而不是遇到图片后丢弃文字。

渲染策略：

- 纯文字章节使用现有文字阅读布局；
- 纯图片章节使用现有漫画画廊、后台解码、占位和缩放逻辑；
- 图文混排章节使用纵向内容容器，按片段顺序插入文字和图片，图片后台解码并限制最大宽度；
- 单个图片读取或解码失败只影响该图片，不影响其他片段和章节切换；
- 章节切换使用代次保护，旧章节后台结果不能覆盖新章节。

EPUB builder 生成的小说章节图片暂按现有资源引用方式保留，读取器通过章节 XHTML 中的图片引用解析资源路径。

### 4. 本地目录跳转

`EpubView._populate_toc()` 为每个 `QListWidgetItem` 写入对应章节索引到 `Qt.UserRole`；点击时校验索引范围，调用 `_load_chapter(index)`，同步更新当前行、进度文本和章节内容。目录顺序严格跟随 `FastEpub.spine_hrefs` 或合并文档拆分结果。

小说和漫画共用这套索引规则；目录为空或索引失效时不抛异常。

## 错误处理

- 下载章节失败沿用现有重试和失败章节记录，不提前写入无效材料。
- 图片提取、下载、读取、解码失败均降级为文字或其他可用内容。
- 旧异步任务回调必须经过章节/书籍代次校验。
- EPUB 合成前发现材料缺失时不伪造章节；沿用现有任务失败状态。

## 测试验收

先写失败测试并确认 RED，再实现：

1. 并发完成顺序与章节索引相反时，EPUB builder 接收到的章节仍为目录顺序；重复重试不会重复章节。
2. 线上小说图片接口返回正文文字和去重后的绝对图片 URL；旧 `fetch_chapter()` 仍只返回文字。
3. NovelView 开启图片时调用异步图片加载器，关闭或换章后旧回调不会插入。
4. 本地 EPUB 目录项的 `Qt.UserRole` 为正确索引，小说和漫画点击目录都会调用对应章节。
5. 本地图文混排章节同时保留文字和图片，并按原始顺序生成渲染片段。
6. 启动性能回归、下载回归、阅读器回归、`compileall` 和 `git diff --check` 通过。
