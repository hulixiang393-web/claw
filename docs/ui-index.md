## 全局快捷键（App 层统一注册）

| 快捷键 | 功能 |
|---|---|
| `Ctrl+1` ~ `Ctrl+8` | 切换对应 Tab |
| `Ctrl+F` | 聚焦搜索关键词 |
| `Ctrl+Enter` | 执行搜索 |
| `Ctrl+D` | 选中项加入下载 |
| `F5` | 刷新当前页 |
| `Ctrl+Shift+S` | 打开设置 |
| `Ctrl+,` | 打开源管理 |
