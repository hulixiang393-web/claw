# 主题与画风规范

> 二次元向桌面 GUI 的统一视觉契约。框架本体不感知，主题切换不引发业务逻辑变更。
> 配套展示入口：所有 token 在浅色 / 深色下都有对应实现。

---

## 1. 设计目标

- **观感**：轻量、温暖、可亲。面向中文小说 / 漫画 / 视频聚合场景，避免冷感与工业感。
- **工程化**：所有色 / 圆角 / 阴影 / 字号都通过 **token** 表达，代码中不写死任何十六进制值。
- **可访问**：所有正文对背景的对比度 ≥ 4.5:1（浅色）/ 7:1（深色）。
- **可切换**：主题切换实时生效，不刷新页面 / 不重启进程。

---

## 2. 主题清单

| 主题 key | 名称 | 风格 |
|---|---|---|
| `sakura` | 樱花粉（默认浅色） | 桃雪背景 + 樱粉强调 |
| `mint` | 薄荷绿（备选浅色） | 奶油白背景 + 薄荷绿强调 |
| `midnight` | 夜樱紫（深色） | 紫夜背景 + 霓虹粉强调 |

未来可扩展：`ocean`（海蓝）、`matcha`（抹茶）。所有主题的字段集必须一致。

## 4. 形状 / 阴影 / 节奏

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 6px | 标签、徽章 |
| `--radius-md` | 12px | 按钮、输入框、卡片（默认） |
| `--radius-lg` | 20px | 主面板、对话框 |
| `--radius-pill` | 999px | 胶囊按钮 |
| `--shadow-1` | `0 2px 6px rgba(0,0,0,0.06)` | 卡片静默态 |
| `--shadow-2` | `0 6px 16px rgba(0,0,0,0.10)` | 卡片悬浮 |
| `--shadow-glow` | `0 4px 16px var(--glow)` | 主按钮悬浮 |
| `--space-1 / 2 / 3 / 4 / 5` | 4 / 8 / 12 / 16 / 24 px | 间距节奏 |
| `--transition-fast` | 120ms | 颜色 / 透明度 |
| `--transition-mid` | 220ms | 缩放 / 阴影 |

## 5. 字体

| 场景 | 中文 | 英文 / 数字 |
|---|---|---|
| 显示标题 | 汉仪乐喵体 / 站酷文艺体 | M PLUS Rounded 1c / Quicksand |
| 正文 | 思源黑体 Rounded / 阿里巴巴普惠体 Rounded | Nunito Rounded |
| 辅文 / 标签 | 思源黑体 Rounded Regular | Nunito Rounded Light |
| 代码 | 思源等宽 / 霞鹜文楷 Mono | JetBrains Mono Rounded |

字号尺度（rem）：`0.75 / 0.875 / 1.0 / 1.125 / 1.25 / 1.5 / 1.875 / 2.25`，可在设置面板里整体缩放（`ui.font_scale`）。

---

## 6. 视觉规则

- **圆角统一**：默认 12px；只在大块面板（20px）和胶囊（999px）两处突破。
- **按钮 hover**：`transform: scale(1.03) + box-shadow: var(--shadow-glow)`，过渡 120ms。
- **空状态**：必须有 Q 版插画 + 一句二次元台词（"还没有源哦，要不要找一只？"），禁止光秃秃的占位符。
- **Loading**：花瓣 / 蝴蝶结 / 猫爪印进度环，不用默认 spinner。
- **错误**：红色感叹号 + 圆角徽章 + 详细可点击的修复建议（"打开源配置诊断"按钮）。
- **吉祥物 logo**（可选）：运行中 / 报错 / 待机 三种表情，作为应用角标。

---

## 7. 插画与字体来源

- **占位插画**：CC0 / 自制 / 委托，禁止使用未授权的角色 / 商业素材。
- **字体**：思源黑体 / 汉仪乐喵体务必保留版权声明。
- **图标**：建议 lucide / phosphor 圆角风格，若需二次元专用图标可补充自有库。

---

## 8. 落地路径

| 技术栈 | 实现方式 |
|---|---|
| **PySide6 / PyQt6** | QSS 模板按 token 生成；运行时切 `qApp.setStyleSheet(...)` 即可。 |
| **Tauri (Web 桌面)** | 自定义 Theme for shadcn / DaisyUI；CSS Variables 集中维护。 |
| **Electron** | Tailwind CSS theme.extend + CSS Variables。 |
| **浏览器样式（开发中）** | 直接读 `docs/theme.md` 复制 token 进样式表。 |

每条路径都要实现三个原则：
1. 主题切换 **不刷新** 主窗口；
2. 至少提供 `sakura` + `midnight` 双主题；
3. 字体大小、圆角、阴影 **不写死**。

---

## 9. 反例（不要做）

- ❌ 渐变背景（`linear-gradient` 整屏）—— 视觉嘈杂。
- ❌ Material Design 默认 ripple 波纹——二次元不要工业感。
- ❌ Emoji 作为 UI 图标——使用线性图标库。
- ❌ 紫色 + 黑色科幻配色——不是二次元，是赛博朋克。
- ❌ 圆角 + 拟物按钮混搭——风格不统一。
