## 一、项目总览

### 1.1 项目一句话

配置驱动的**多源爬虫桌面应用**（PySide6 + framework 内核），一个 GUI 同时挂多个小说/漫画/视频源，规则全外置（源 JSON + 广告规则库），支持浏览、搜索、阅读、下载、书架、源管理。

### 1.2 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 内核 | Python + 标准库为主 | `framework/` 纯 Python，规则外置零硬编码 |
| GUI | PySide6 / PyQt6 | 桌面界面，QSS 按 token 生成主题 |
| 配置 | JSON + YAML | 源配置（JSON）、全局设置（JSON）、广告规则（YAML） |
| 存储 | JSON + SQLite | 收藏/历史/续读用 JSON；书架索引用 SQLite |
| 可选依赖 | requests / lxml | HTTP 与 HTML 解析（未装则标准库降级） |

### 1.3 三态吉祥物（二次元风格）

- **待机**（空闲）、**运行**（后台任务）、**报错**（源失效）三态，由 EventBus 事件驱动。
- 插画成品资源第二阶段替换；本阶段完成组件框架 + 三态逻辑 + 占位绘制。

## 四、内核 API 调用逻辑

> 每个界面如何调用内核 API。详细模块见 `core.md`。

### 4.1 统一入口：Scheduler

GUI 所有操作经由 `Scheduler` 门面，或订阅 `EventBus` 异步事件。

```
Scheduler
  ├─ 搜索     : search_type(content_type, keyword) -> SearchReport
  │              search_one(source_id, keyword) -> List[SearchResult]
  ├─ 发现     : list_categories(source_id) -> List[Category]
  │              list_works(source_id, category_url) -> List[SearchResult]
  ├─ 内容     : fetch_detail(source_id, url) -> ContentResult
  │              fetch_chapter(source_id, chapter_url) -> str
  │              fetch_comic(source_id, episode_url) -> List[str]
  │              fetch_video(source_id, episode_url) -> str
  ├─ 下载     : download(source_id, url, max_items) -> List[str]
  ├─ 全量抓取 : bulk_fetch(source_id) -> BulkResult（异步，进度经 EventBus）
  ├─ 书架     : library.list() / library.add_favorite() / library.resume_position()
  ├─ 诊断     : selftest(source_id) -> bool
  └─ 配置     : manager.all() / manager.get(source_id) / manager.set_enabled()
```

### 4.2 各界面调用逻辑表

| 界面 | 操作 | 内核调用 | 返回 |
|---|---|---|---|
| 首页 | 统计卡片 | `SourceManager.all()` | 按类型/启用/失效分组 |
| 首页 | 最近搜索 | `SearchHistory.load()` | 最近 20 条 |
| 首页 | 迷你进度 | EventBus `SEARCH_*`/`DOWNLOAD_*` | 事件 |
| 首页 | 批量更新 | `bulk_fetch.check_updates()` | 各源新章节数 |
| 发现 | 选源看分类 | `list_categories(source_id)` | `[Category]` |
| 发现 | 分类列表 | `list_works(source_id, cat_url)` | `[SearchResult]` 懒加载 |
| 发现 | 全量抓取 | `bulk_fetch(source_id)` 异步 | 进度事件 |
| 搜索 | 触发搜索 | `search_type(type, kw)` 并发 | `SearchReport` |
| 搜索 | 源状态 | EventBus `SEARCH_PROGRESS` | 事件 |
| 搜索 | 来源筛选 | 前端过滤 `result.source_id` | — |
| 阅读器 | 拉详情 | `fetch_detail(source_id, url)` | `ContentResult` |
| 阅读器 | 拉正文 | `fetch_chapter(source_id, ch_url)` | 正文文本（已过 adblock） |
| 阅读器 | 拉漫画 | `fetch_comic(source_id, ep_url)` | 图片 URL 列表 |
| 阅读器 | 拉视频地址 | `fetch_video(source_id, ep_url)` | 解密后播放地址 |
| 阅读器 | 续读 | `library.resume_position(source_id, book_url)` | 最后位置 |
| 下载 | 加入队列 | `download_queue.add(book, chapters)` | 任务 id |
| 下载 | 进度 | EventBus `DOWNLOAD_PROGRESS` | 事件 |
| 书架 | 列书库 | `library.list()` | 作品列表 |
| 书架 | 收藏 | `library.add_favorite(book)` | — |
| 源管理 | 列源 | `SourceManager.all()` | `[SourceConfig]` |
| 源管理 | 诊断 | `selftest(source_id)` | bool + 健康灯 |
| 源管理 | 启停 | `manager.set_enabled(source_id, bool)` | — |
| 源管理 | 权重 | `manager.set_weight(source_id, float)` | — |
| 编辑器 | 实时预览 | `preview.validate_selector(source, url, field, sel)` | `PreviewResult` |
| 编辑器 | 测试搜索 | `preview.preview_search(source, kw)` | 结果预览 |
| 编辑器 | 保存 | `SourceConfig.from_dict(cfg)` 校验 → 落盘 | 校验结果 |

### 4.3 广告过滤 API（adblock）

```
adblock.filter_content(content_type, html/text/images, source) -> 过滤后内容
  - novel  : filter_novel_body(html, rules) -> 清洗后正文
  - comic  : filter_comic_images(images, rules) -> 剔除广告图
  - video  : filter_video_page(html, rules) -> 屏蔽广告DOM / filter_m3u8(playlist, rules) -> 剔除广告段
  - 规则加载 : load_rules(content_type) -> 全局该类型规则 + 源级补充合并
```

### 4.4 EventBus 事件常量（framework/events.py）

```
SEARCH_STARTED / SEARCH_PROGRESS / SEARCH_COMPLETED / SOURCE_ERROR
DOWNLOAD_STARTED / DOWNLOAD_PROGRESS / DOWNLOAD_COMPLETED / DOWNLOAD_FAILED
STRUCTURE_CHANGED / LOG / THEME_CHANGED / BULK_FETCH_PROGRESS / BULK_FETCH_COMPLETED
```
